# Coucou for Windows

This folder is the Windows app (Tauri 2: Rust + TypeScript). The full guide, including rules, layout, build commands and the Windows-specific section, is in the repo root `CLAUDE.md`, which loads alongside this file.

- Run commands from this folder (`npm run tauri dev`, `npm run build`); run git from the repo root `E:\Projects\coucou`.
- Keep code changes inside `windows/` unless the task is explicitly cross-platform.
- User-facing docs for this app: `windows/README.md`.
